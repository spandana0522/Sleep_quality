# Sleep Quality Prediction System

# Overview

Sleep Quality Prediction System is a machine learning project that predicts a person's sleep quality based on factors such as sleep duration, caffeine intake, stress level, and bedtime consistency. The project uses Linear Regression to analyze how lifestyle habits affect sleep quality.

# Features

* Sleep quality prediction using Linear Regression
* Data preprocessing and analysis
* Performance evaluation using R² Score and MAE
* Data visualization with graphs and charts
* User-friendly prediction workflow

# Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

# Input Parameters

* Sleep Duration (Hours)
* Caffeine Intake (mg)
* Stress Level
* Bedtime Consistency

# Workflow

1. Load and preprocess the dataset.
2. Train the Linear Regression model.
3. Evaluate model performance.
4. Generate predictions.
5. Visualize results using charts.

# Benefits

* Identifies factors affecting sleep quality
* Demonstrates practical machine learning implementation
* Provides data-driven insights for healthier habits
